# TFM - Analítica y recomendaciones para microempresas rurales

Este repositorio contiene el desarrollo incremental del Trabajo Final de Máster del Máster en Big Data e Inteligencia Artificial.

El proyecto propone un prototipo de analítica comercial y recomendaciones operativas para microempresas pequeñas y rurales. El objetivo es transformar datos simples de ventas, clientes y productos en indicadores, segmentaciones y recomendaciones accionables.

## Estructura del repositorio

- `docs/entregas/`: entregas incrementales del proyecto.
- `data/`: datos brutos, procesados y sintéticos.
- `notebooks/`: análisis exploratorio y pruebas.
- `src/`: código reutilizable del proyecto.
- `reports/`: gráficos, resultados e informes.
- `app/`: futura aplicación o dashboard interactivo.

## Entregas

- `docs/entregas/01_ideas_producto.md`: propuestas iniciales de producto.
- `docs/entregas/02_datos_necesarios.md`: selección de idea y análisis de datos necesarios.
